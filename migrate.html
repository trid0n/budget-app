Budget app — one-time Supabase migration

Moves everything from the old browser-local IndexedDB storage into Supabase, under one logged-in account. Run this once, then this file is no longer needed.

  1. Open the currently deployed app (or legacy/budget-assign.html) in a browser, open DevTools → Console, and run: 
    copy(JSON.stringify(await (async()=>{const out={};const r=await window.storage.list('',false);for(const k of r.keys){const v=await window.storage.get(k,false); out[k]=v.value;} return out;})()))
    This copies a full dump of every stored key to your clipboard.
  2. Paste it into the box below.
  3. Log in below with the account you created via the new app's sign-up screen (the migration writes rows owned by whichever account you're logged in as).
  4. Click Run migration. Safe to re-run — each table is fully replaced per run, not appended to.
